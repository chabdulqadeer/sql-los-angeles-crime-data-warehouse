# Los Angeles Crime Dataset

## 📌 Overview

This dataset contains crime records from Los Angeles City and is used for SQL-based Data Warehouse and Analytics projects.

The dataset includes crime incidents reported from 2020 onwards and contains detailed information about:
- Crime types
- Victim demographics
- Weapons used
- Geographic locations
- Premises
- Date and time information

This dataset is suitable for:
- SQL practice
- Data Warehousing
- ETL projects
- Data Cleaning
- Dimensional Modeling
- Advanced SQL Analytics
- Window Function Practice

---

# 📊 Dataset Features

- Real-world crime data
- Large-scale dataset
- Multiple categorical dimensions
- Time-series analysis capability
- Geographic analysis capability
- Suitable for analytical querying

---

# 🧾 Included Information

The dataset contains columns related to:

- Crime IDs
- Crime descriptions
- Area information
- Victim age, gender, and descent
- Weapon information
- Premise descriptions
- Crime occurrence date and time
- Geographic coordinates

---

# 🏗️ Project Usage

This dataset is used in a Medallion Architecture-based Data Warehouse project with:

- Bronze Layer → Raw data ingestion
- Silver Layer → Cleaned and standardized data
- Gold Layer → Analytical and reporting layer
